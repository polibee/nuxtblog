# 11. Restore ID Mapping

非常重要。

不能假设：

```text
旧 ID = 新 ID
```

必须支持：

```text
Backup ID
↓
Restore ID
```

例如：

```text
old post id = 100

new post id = 342
```

映射：

```ts
context.mapId(
  "posts",
  100,
  342
)
```

关系恢复：

```text
post_categories.post_id
```

通过 Mapping 转换。

---

# 12. 为什么必须 Mapping

否则：

```text
Media ID
User ID
Post ID
Category ID
```

只要目标库已有数据：

Restore 就会冲突。

# 13. Restore 模式

建议两种。

### Replace

```text
清空业务数据
↓
Restore Backup
```

用于灾难恢复。

### Merge

```text
保留现有数据
↓
导入 Backup
↓
重新映射 ID
```

用于迁移。

第一版可以先：

```text
Replace
```

做好。

Merge 后续。
