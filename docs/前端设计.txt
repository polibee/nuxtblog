你现在想到的核心已经够做出一个很完整的个人博客前台了。我建议不要把前台做成“门户站”，而是保持 **内容优先、两栏清晰、信息密度适中、文章页阅读体验最好**。

# Nuxt 全栈博客前端页面设计文档

## 1. 前端整体定位

前台不是后台功能的简单展示层，而应该围绕：

```text
阅读文章
发现文章
浏览分类
参与评论
继续阅读
```

五个核心行为设计。

整体视觉建议：

```text
简洁
内容优先
中等信息密度
轻卡片化
不过度圆角
不过度 Dashboard 化
桌面端两栏
移动端单栏
```

不要把博客前台做成：

```text
Admin Dashboard 风格
大量 Widget
满屏 Card
复杂渐变
几十种按钮
```

---

# 2. 全站布局

桌面端：

```text
┌─────────────────────────────────────────────┐
│                  Header                     │
│ Logo     Navigation        Search / Account │
├─────────────────────────────────────────────┤
│                                             │
│ ┌─────────────────────────┐ ┌─────────────┐ │
│ │                         │ │             │ │
│ │       Main Content      │ │   Sidebar   │ │
│ │                         │ │             │ │
│ │                         │ │             │ │
│ └─────────────────────────┘ └─────────────┘ │
│                                             │
├─────────────────────────────────────────────┤
│                  Footer                     │
└─────────────────────────────────────────────┘
```

推荐宽度：

```text
max-width: 1280px ~ 1360px
```

内容比例：

```text
Main:
约 72%

Sidebar:
约 28%
```

或者：

```text
Main 860px
Sidebar 300px
Gap 32px
```

不要侧边栏太宽。

建议：

### Level 1




# 98. 最终设计原则

前端必须始终遵守：

```text
内容 > Widget

阅读 > 动画

结构 > 装饰

信息层级 > 信息数量

桌面两栏
移动单栏

正文优先
Sidebar 辅助

Card 用于发现
Article 用于阅读

评论支持讨论
但不做论坛

多语言由数据驱动
广告由 AdSlot 驱动
导航由后台数据驱动
```

最终你这个博客前台应该呈现为：

> **一个现代、信息密度适中、技术内容阅读体验很强的两栏个人博客（通用博客，不只是技术博客），而不是一个 CMS 默认主题，也不是一个 Dashboard 风格网站。**

你现在最值得重点打磨的其实不是再增加更多前台模块，而是三个核心体验：**文章列表的信息层级、长文阅读（TOC/代码/图片/表格）、评论楼中楼**。这三块做好以后，整个前台质感基本就定下来了。
